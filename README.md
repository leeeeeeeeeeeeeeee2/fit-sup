# [핏썹(FIT'SUP) 크루저 보드 브랜드 사이트 UX/UI 프로젝트]

> 신발 사이즈 기반 보드 길이 추천과 컬러 조합 미리보기로, 처음 크루저 보드를 고르는 사람도 나에게 맞는 보드를 쉽게 찾을 수 있도록 설계한 가상 브랜드 사이트

- **제작 기간**: 2026.11.12 ~ 2026.11.16 (5일)

- **담당 범위**: 브랜드 콘셉트 기획 → Figma 디자인 → 바이브코딩 구현 → GitHub Pages 배포

## 3. 사용 기술

- **React, Vite**: 컴포넌트 기반 UI 구조화 및 빠른 개발 환경 구축
- **GitHub Pages**: 정적 사이트 배포
- **Figma**: 브랜드 아이덴티티, 와이어프레임 및 화면 디자인
- **Claude**: 바이브코딩 (화면 구현)

## 4. 주요 기능

- 기능 1: 신발 사이즈 기반 보드 길이 추천: 신발 사이즈를 입력하면 발 크기에 맞는 보드 길이를 추천해, 스펙을 몰라도 자신에게 맞는 보드를 고를 수 있도록 함
- 기능 2: 컬러 조합 미리보기: 데크·휠·트럭 등 부품별 컬러를 직접 골라 조합하고, 완성된 보드 모습을 실시간으로 확인
- 기능 3: 모바일 최적화 반응형 레이아웃: 스마트폰에서도 컬러 선택과 사이즈 입력을 쉽게 조작할 수 있는 터치 친화적 UI 디자인

## 5. 트러블슈팅

### 이슈 1:

- **문제**: 컬러 칩을 눌러 데크·휠·트럭 색상을 바꿔도 미리보기 이미지가 바로 바뀌지 않거나, 다른 부품 색상이 초기값으로 돌아가는 현상 발생
- **원인**: 부품별 색상 상태를 각 컴포넌트에서 따로 관리해, 한 부품의 색을 바꿀 때 다른 부품의 선택값이 공유되지 않음
- **해결**: 데크·휠·트럭 색상을 하나의 상태 객체로 묶어 상위 컴포넌트에서 관리하고, 미리보기와 컬러 칩이 같은 상태를 참조하도록 구조를 변경해 선택한 조합이 실시간으로 반영되도록 해결

## 6. AI 활용 방식

- **맡긴 일**: Figma에서 디자인한 시안을 바탕으로 React 기반의 사이즈 추천·컬러 조합 컴포넌트 및 인터랙션 구현
- **핵심 프롬프트**: "크루저 보드를 처음 사는 사람은 어떤 길이의 보드가 자기에게 맞는지 몰라서 고르기 어려워. 신발 사이즈를 입력하면 발 크기에 맞는 보드 길이를 추천해 주고, 데크·휠·트럭 색상을 직접 골라 완성된 보드 모습을 바로 볼 수 있는 화면을 만들어줘. 모바일에서도 한 손으로 쉽게 고를 수 있게 버튼과 컬러 칩은 크게 배치해줘."


## 7. 회고

배운 점 : 실제 존재하지 않은 브랜드를 처음부터 기획하며, 제품을 파는 사이트가 아니라 사용자가 나에게 맞는 보드를 직접 찾아가도록 돕는 경험을 설계해 보았다. 브랜드 콘셉트 기획부터 Figma 디자인, 코드 구현, 배포까지 혼자 끝까지 완성해 냈다.

아쉬운 점 : 보드 길이 추천이 신발 사이즈만을 기준으로 한 단순한 규칙이라, 키·라이딩 스타일·숙련도 같은 실제 선택 요소를 반영하지 못한 점이 아쉬웠다. 따라서 다음 프로젝트에서는 추천 기준을 세분화하고, 실제 사용자 테스트로 추천 결과의 만족도를 검증해 볼 계획이다.
