# Logos

보드 옆모습 심볼이에요(덱 막대 + 바퀴 두 개). 옆에 "핏썹" 워드마크를 Black Han Sans 30px로 조판해서 함께 써요. 워드마크는 글꼴로 쓰는 글자라 파일이 따로 없어요.

- `fitsup-mark-ink.svg`: 밝은 바탕(`ground`, `surface`)용. 잉크 `#111311` 한 색.
- `fitsup-mark-white.svg`: `ink` 바탕(푸터)용. 흰색 한 색.
- 심볼은 44×26 비율 그대로 쓰고, 브랜드 블루나 다른 색으로 칠하지 않아요.
- 최종 로고 파일은 4단계에서 확정했지만, 워드마크를 윤곽선으로 만든 파일은 아직 없어요.
