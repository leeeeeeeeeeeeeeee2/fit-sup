# 핏썹

사이즈는 딱 맞게, 디자인은 내 맘대로. 처음 보드를 사는 10대 후반~20대 중반 입문자가 크루저 보드(22·27·32인치) 길이를 추천받고, 덱·바퀴·트럭 색과 무늬·문구를 골라 주문까지 하는 사이트의 디자인 시스템이에요. 2026-11-13 기준 Claude Design 캔버스 「핏썹(FIT'SUP) 시각 디자인」의 P01~P06 화면에서 실제로 쓰인 값만 모았어요.

콘셉트는 **아스팔트 위의 스티커**예요. 밝은 콘크리트 바탕(`ground`)에 검정 선(`ink`)을 긋고, 누를 곳에만 핏썹 블루(`brand`) 스티커를 붙여요. 선과 단단한 그림자로 물건을 구분하고, 흐린 그림자나 그라데이션은 쓰지 않아요.

## 원칙

1. **색은 장식이 아니라 구분이다.** 화면 대부분은 `ink`·`ground`·`surface` 세 가지로 만들어요. 다른 색이 나오면 그 자리에 의미가 있어야 해요.
2. **블루는 행동과 신뢰에만.** `brand`는 핵심 행동 버튼(보드 만들기 시작, 장바구니 담기, 주문하기, 가상 결제 완료하기, 로그인하기, 로그인하고 계속하기)과 P01 S01-4 구매 전 확인 넓은 면, 완료 표시 원에만 써요.
3. **입문자에게 쉽게.** 보드 용어는 괄호로 풀어 써요. 예: "트럭(바퀴를 잡아 주는 부품)".
4. **나만의 보드가 주인공.** 제품 옵션색(`deck-*`)은 보드 그림 안에서만 쓰고, 버튼이나 바탕 같은 UI에는 섞지 않아요.

## 말투

보드 잘 타는 친한 선배가 존댓말로 쉽게 알려 주는 말투예요. 문장은 짧게, "~해요"로 끝내요.

- 좋음: "키만 알려 줘요. 나머진 우리가 딱 맞춰 볼게요."
- 좋음: "추천은 확인용 예시 규칙이에요. 아래에서 다른 길이를 골라도 돼요."
- 피함: 구매를 재촉하는 말("지금 아니면 품절!"), 전문가 용어만 쓰는 설명, 유치한 말투.
- 조사는 받침에 맞춰요: 서프 스케이트**로** · 카빙**으로** · 사이드와인더**로** · 크루저**로**.

## 컬러

| 토큰 | 쓰는 곳 |
| --- | --- |
| `ground` | 페이지 기본 바탕 |
| `surface` | 카드·패널·입력칸, 구간을 나누는 흰 바탕(P01 S01-2) |
| `ink` | 글자, 1.5px 선, 그림자, 선택 상태, 푸터 |
| `text-muted` / `text-caption` | 설명 글 / 캡션 |
| `brand` + `on-brand` | 핵심 행동 버튼, 구매 전 확인 넓은 면 |
| `error` | 입력 오류(빨간 테두리 + 아이콘 + 고치는 방법) |
| `deck-*`, `truck-silver` | 보드 그림 안에서만 |

- 선택 상태는 색이 아니라 **반전**(ink 바탕 + 흰 글자)이나 **두꺼운 ink 테두리(2.5px) + ✓**로 보여 줘요.
- `line-soft`는 선택되지 않은 카드 테두리로만 써요. 대비가 낮으니 혼자서 상태를 알리면 안 돼요.
- 기록: 처음에는 핵심 버튼 강조색으로 라임(#C8F03C)을 정했어요. 이후 캔버스에서 블루로 바뀌어 지금은 `brand` 하나가 버튼과 넓은 면을 함께 맡아요. 기획서의 "버튼 강조색과 넓은 면 색은 역할을 나눈다" 원칙과는 다르니 확정이 필요해요.

## 타이포그래피

- 제목: **Black Han Sans**(`display`). 굵기는 하나뿐이라 크기로 위계를 만들어요. 80 → 64 → 56 → 48 → 44 → 32px.
- 본문·UI: **Noto Sans KR**(`sans`) 400·500·700. 본문 줄 간격은 1.7~1.8로 넓게 잡아요.
- 영문 대문자 제목은 쓰지 않아요. 줄바꿈은 단어 단위(`word-break: keep-all`)로 해요.
- 덱 문구 글꼴 4종(스프레이·페인트·펜·두꺼운)은 보드 그림 안에서만 써요. 문구는 `ink` 글자에 흰 테두리(paint-order: stroke)를 두르고 -4° 기울여요.
- 글꼴은 모두 Google Fonts에서 불러와요: `family=Black+Han+Sans&family=Noto+Sans+KR:wght@400;500;700`. 덱 문구가 있는 화면만 `Rubik+Spray+Paint`, `Permanent+Marker`, `Nanum+Pen+Script`를 더해요.

## 레이아웃

- 데스크톱 기준 1440px, 내용 최대 너비 1200px, 좌우 여백 24px.
- 여백은 넓게 써요. 메인 섹션 위아래 120px, 섹션 제목과 카드 묶음 사이 56px, 카드 사이 24px.
- 섹션은 늘 "제목 + 보조 글 → 카드 묶음" 순서예요. 구간마다 바탕을 `ground` ↔ `surface` ↔ `brand` ↔ `ink`(푸터)로 바꿔 경계를 만들어요.
- 카드는 같은 틀을 반복해요. 사진 위·정보 아래, 왼쪽 정렬, 버튼은 맨 아래에 맞춰요.
- 모든 화면은 헤더(M01~M05) → 본문 → 푸터 순서예요.

## 반복 요소

- **버튼은 모두 알약 모양**(`radius-pill`)이에요. 종류는 세 가지예요.
  - 주요: 64px, `brand` 바탕, 흰 글자, `ink` 2.5px 테두리, `shadow-action`. 한 화면에 하나가 원칙이에요.
  - 보조: 48~52px, `surface` 바탕, `ink` 1.5px 테두리, 그림자 없음.
  - 텍스트: 밑줄 글자 버튼(추천 건너뛰기, 닫기, 계속 꾸미기).
- **모서리**: 카드 20 · 큰 패널 28 · 입력칸과 사진 14 · 정보 상자 16 · 알림 18 · 버튼과 칩 999.
- **선**: 기본 1.5px, 묶음 상자 2px, 선택·주요·오류 2.5px.
- **그림자**: 오른쪽 아래로 밀린 단단한 `ink` 그림자만 써요. 알림 하나만 예외로 부드러운 그림자를 써요.

## 아이콘

인라인 SVG 선 아이콘이에요. 선 굵기 2~2.5px, 둥근 끝, 색은 주변 글자색을 따라요. 화살표(→ ↓), 체크, 정보(i), 휴지통, 내려받기, 카메라(사진 자리), 자물쇠(로그인 필요), 연필(직접 만들기)을 써요. 이모지는 쓰지 않아요. 글자 없이 아이콘만 있는 버튼에는 `aria-label`을 붙여요.

## 보드 그림

- 윗면: 덱은 `radius-pill`처럼 끝이 둥근 긴 막대(덱 높이의 절반만큼 모서리)이고, 바퀴 4개가 위아래로 살짝 보여요. 선은 `ink` 4~5px.
- 옆모습: 얇은 덱 아래에 `truck-silver` 트럭과 바퀴 2개를 그려요. 바퀴 가운데에는 흰 축 원을 넣어요.
- 무늬: 무지 · 스트라이프 · 체커 · 플레임 + 직접 만들기. 체커 칸은 덱 높이에 맞춰 20px(썸네일 6px)이에요.
- 그림에는 반드시 구성 문장을 대체 텍스트로 붙여요. 예: "블루 덱, 체커 무늬, 스프레이 스타일 leeeee 문구, 블랙 바퀴 보드의 윗면".

## 이미지

라이딩 사진은 동작이 가장 크게 드러나는 실제 야외 장면을 써요. 네 장 모두 4:5 비율로 맞춰요. 사진이 들어오기 전에는 `placeholder` 바탕에 카메라 아이콘과 "라이딩 사진 자리"를 표시해요.

## 로고

`Logos` 그룹의 보드 옆모습 심볼에 "핏썹" 워드마크(Black Han Sans 30px)를 붙여 써요. 밝은 바탕에서는 ink, 푸터처럼 ink 바탕에서는 흰색을 써요. 브랜드 블루로 칠하지 않아요.

## 접근성

- 글자 대비 4.5:1 이상. 모든 조합이 기준을 넘지만 `line-soft` 테두리만 예외예요(위 컬러 참고).
- 클릭 영역은 44px 이상이에요. 선택 버튼에는 `aria-pressed`, 탭에는 `role="tab"`, 미리보기 구성 문장에는 `aria-live="polite"`를 붙여요.
- 오류는 빨간 테두리 + 아이콘 + 고치는 방법 문장으로 알려요.

## 쓰지 않는 것

할인율 배지, 취소선 가격, 빨간 판매가, 별점·리뷰 수, '함께 보기' 추천 줄, 슬라이드 화살표, 그라데이션, 이모지, 영문 대문자 제목.

## 아직 정하지 않은 것

가격·배송비 표기, 사업자 정보, 실제 결제 화면(체험용 문구를 지울지), 인터랙션 움직임, 모바일 배치, 최종 로고 파일, 라이딩 사진.
