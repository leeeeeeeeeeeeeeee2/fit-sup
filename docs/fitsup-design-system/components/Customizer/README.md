# Customizer

P02 S02-3 오른쪽 묶음의 꾸미기 선택 요소예요. 위에서 아래로 길이 구간 → 부품 탭 → 부품 설명 → 색상 → 무늬 → 문구 → 문구 스타일 순서로 놓아요.

- **길이 구간 버튼**: `surface` 알약 틀 안에 3칸. 선택 칸은 `ink` 바탕 + 흰 글자.
- **부품 탭**(덱/바퀴/트럭): 위 모서리만 둥근(`radius-md`) 탭, 선택 탭은 `ink` 반전. 탭마다 쉬운 설명 상자가 바뀌어요.
- **색 견본**: 40px 원 + 이름. 선택은 견본 바깥 2.5px `ink` 고리 + 이름 700. 견본 아래에 '#'이 붙은 6자리 색 코드 입력칸(직접 입력)을 둬요. 판매 색상 목록은 [미정]이에요.
- **무늬 타일**: 무지 · 스트라이프 · 체커 · 플레임 · 직접 만들기(점선 테두리 + 연필 아이콘). 타일 견본은 지금 고른 덱 색으로 칠해요.
- **문구 스타일 타일**: 페인트 · 스프레이 · 펜 · 두꺼운. 각 타일에 해당 글꼴로 쓴 "Aa"를 보여 줘요.
- 무엇을 바꾸든 왼쪽 미리보기와 구성 문장이 함께 바뀌고, 구성 문장은 `aria-live="polite"`로 읽어 줘요.
