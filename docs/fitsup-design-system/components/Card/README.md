# Card

같은 틀을 반복하는 정보 묶음이에요. 사진 위·정보 아래, 왼쪽 정렬, 버튼은 맨 아래에 맞춰요.

- **스타일 카드**(P01 S01-2): `ground` 바탕(흰 구간 위), 테두리 없음, 안쪽 14px. 4:5 사진 → 소제목(22px) → 보조 글 → 보조 버튼. 네 장을 한 줄에 같은 크기로 놓고 슬라이드는 쓰지 않아요.
- **단계 카드**(P01 S01-3): `surface` 바탕 + `ink` 1.5px 테두리, 안쪽 36/32/40px. 큰 숫자(Black Han Sans 64px)는 실제 순서가 있을 때만 붙여요.
- **저장한 디자인 카드**(P05): 보드 윗면 썸네일 → 이름(19px 700) → 구성 문장 → 다시 꾸미기(보조) + 장바구니 담기(주요·작게).
- 모서리는 `radius-card`(20px), 카드 안 사진·썸네일은 `radius-md`(14px)예요.
- 카드 사이 간격은 24px로 맞춰요.
