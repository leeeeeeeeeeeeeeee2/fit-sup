# TextField

라벨이 위에 붙는 입력칸·드롭다운이에요. 키, 신발 사이즈, 덱 문구, 배송 정보에 써요.

- 높이 56px, `surface` 바탕, `ink` 1.5px 테두리, `radius-md`(14px), 글자 17px.
- 라벨은 칸 위에 16px 700으로 둬요. 안내 문구(placeholder)는 "~을 입력해 주세요 · 예: …" 형식이에요.
- 오류: 테두리를 `error` 2.5px로 바꾸고, 칸 아래에 아이콘 + 고치는 방법 문장을 붙여요(`aria-invalid`, `aria-describedby`).
- 덱 문구 칸 아래에는 글자 수("6/12자")와 안내를 둬요. 최대 글자 수는 [미정](예시 12자)이에요.
