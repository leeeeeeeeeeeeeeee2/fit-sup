# OptionCard

여러 개 중 하나만 고르는 카드형 선택지예요. P02 S02-2의 타는 스타일·길이 고르기에 써요.

- `button` + `aria-pressed`로 만들어요.
- 기본: `ground` 바탕, `line-soft` 1.5px 테두리.
- 선택(스타일): `ink` 바탕 + 흰 글자로 반전하고, 소제목 뒤에 "✓"를 붙여요.
- 선택(길이): 바탕은 그대로 두고 `ink` 2.5px 테두리 + "✓". 추천된 카드에는 '추천' 칩을 붙여요.
- `line-soft` 테두리는 대비가 낮아요. 선택 여부는 반전이나 두꺼운 ink 테두리로만 구분해요.
- 길이 카드 순서는 소제목 → 보드 그림 → 강조 글 → 보조 글이에요(와이어프레임 기준).
