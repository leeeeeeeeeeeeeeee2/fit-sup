# ListRow

장바구니(P03)와 주문 확인(P04 S04-1)에서 담은 보드 한 개를 보여 주는 가로 행이에요.

- 순서: 보드 윗면 썸네일(180×104) → 이름·구성 묶음 → 가격 → 삭제 버튼. 주문 확인에서는 삭제 버튼을 빼요.
- 이름은 "블루 카빙 보드 · 32인치 · 수량 1개"처럼 덱 색 + 스타일 + 보드로 지어요. 구성 문장은 고른 값 그대로예요. 문구가 없으면 "문구 없음".
- 가격은 확정 전까지 "가격 미정"이에요. 할인·취소선 가격은 쓰지 않아요.
- 삭제 버튼에는 어떤 보드를 지우는지 `aria-label`로 알려요.
