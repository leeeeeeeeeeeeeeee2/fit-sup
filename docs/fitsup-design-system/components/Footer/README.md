# Footer

모든 페이지 맨 아래에 같은 모양으로 들어가는 정보 영역이에요. 이미지 저장 창처럼 화면 위에 뜨는 창에는 넣지 않아요.

- `ink` 바탕, 흰 글자. 윗줄에 흰 로고 + 한 줄 소개("사이즈는 딱 맞게, 디자인은 내 맘대로.") / 메뉴, 아랫줄에 이용약관·개인정보처리방침, 사업자 정보, © FIT'SUP을 둬요.
- 사업자 정보(상호·대표자·사업자등록번호·통신판매업 신고번호·주소·고객센터)는 확정 전까지 점선 상자(`on-ink-dashed`)에 안내 문장만 넣어요. 값을 지어내지 않아요.
- 로그인된 상태에서는 메뉴 마지막이 '로그아웃' 버튼이 돼요.
