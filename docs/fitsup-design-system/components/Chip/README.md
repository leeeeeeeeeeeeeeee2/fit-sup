# Chip

짧은 사실이나 상태를 알리는 알약 모양 표시예요. 누를 수 없어요.

- **표시 칩**: `surface` 바탕, `ink` 1.5px 테두리, 15px 700. 예: 히어로의 "크루저 보드 · 22 / 27 / 32인치".
- **안내 칩**: `ground` 바탕에 정보(i)나 체크 아이콘을 붙여요. 예: "체험용 입력란이에요.", "로그인하면 하던 디자인 저장을 이어서 해 드릴게요."
- **추천 칩**: `ink` 바탕, 흰 글자 13px, 높이 28px. 추천 길이 카드의 소제목 옆에만 붙여요.
- **개수 배지**: 헤더 M04 장바구니 옆 24px 원. 화면 읽기 프로그램에는 링크의 `aria-label`("장바구니, 담은 보드 2개")로 알려요.
- 할인율·별점 배지는 만들지 않아요.
