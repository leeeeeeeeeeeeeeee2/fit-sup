# Button

모든 버튼은 알약 모양이고, 주요·보조·텍스트 세 단계로 나눠요.

| 종류 | 모양 | 쓰는 곳 |
| --- | --- | --- |
| 주요 | 높이 64px, `brand` 바탕, `on-brand` 글자 20px 700, `ink` 2.5px 테두리, `shadow-action` | 핵심 행동: B01-1 보드 만들기 시작, B02-4 장바구니 담기, B03-2 주문하기, B04-1 가상 결제 완료하기, B05-3 로그인하기, B06-1 로그인하고 계속하기 |
| 주요(작게) | 높이 48px, 글자 15px, `shadow-action-sm` | 카드 안의 핵심 행동(B05-2 장바구니 담기) |
| 보조 | 높이 48~52px, `surface` 바탕, `ink` 1.5px 테두리, 그림자 없음 | B01-2 스타일로 시작하기, B02-1 내 길이 추천받기, B02-5·6 저장, B03-1 삭제, B04-2·3 |
| 텍스트 | 밑줄 글자, 높이 44px | B02-2 추천 건너뛰기, B02-8 계속 꾸미기, B02-11 닫기 |
| 어두운 바탕 | 흰 1.5px 테두리 + 흰 글자 | 알림 안 B02-7 장바구니 보기 |

- 한 화면 한 구역에 주요 버튼은 하나만 둬요.
- 화살표 아이콘은 다음 화면으로 넘어갈 때만 붙여요(→ 이동, ↓ 같은 페이지 아래로).
- 키보드 초점은 3px `ink` 테두리를 4px 띄워 보여 줘요.
- 담은 보드가 없을 때 B03-2는 비활성으로 보여요. 모양은 [미정]이에요.
