# Header

모든 페이지 맨 위에 같은 모양으로 들어가는 메뉴예요. 순서는 M01 로고 → M02 보드 만들기 → M03 내 디자인 → M04 장바구니(개수) → M05 로그인/로그아웃이에요.

- 높이 80px 이상, `ground` 바탕, 아래 1.5px `ink` 선.
- 현재 페이지 메뉴는 700 + 2px 밑줄(8px 띄움)과 `aria-current="page"`로 표시해요.
- M05는 테두리 알약이에요. 로그인 화면에 있을 때는 `ink` 바탕 + 흰 글자로 반전해요. 로그인된 상태에서는 "로그아웃" 버튼이 돼요.
- 로그인 전에 M03을 누르면 '내 디자인' 로그인 전 안내 화면으로 가요.
- 모바일 헤더는 [미정]이에요(6단계).
