## 5. 먼저 정할 것 (우선순위)

1. **P02 2단계 미리보기 위치 (19번, 27번)**: 미리보기와 옵션이 세로로 쌓이면 옵션을 바꿀 때 결과가 화면 밖에 있어요. 미리보기 상단 고정과 장바구니 바 하단 고정 중에서 고르기.
2. **헤더 메뉴 방식 (1번, 3번)**: 햄버거 메뉴와 아이콘 메뉴 중에서 고르기.
3. **이미지 저장 창 형태 (30번, 31번)**: 전체 화면과 아래에서 올라오는 시트 중에서 고르고, iOS 저장 안내 넣기.
4. **선택 그리드 열 수 (16, 21, 23, 26번)**: 열 수를 줄일지 가로 스크롤로 바꿀지 하나로 통일하기.

- 기준 폭 (2026-11-16 답변): 데스크톱 1024px 이상 / 태블릿 361~1023px / 모바일 360px 이하
