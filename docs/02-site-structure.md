- 근거 문서: [01-site-purpose.md](./01-site-purpose.md)
- 주요 기기: 데스크톱 기준으로 진행

## 1. 확정한 사항

### 구성 방식 선택

| 번호 | 선택 항목 | 확정 내용 |
|---|---|---|
| ① | 길이 찾기와 디자인의 배치 | 한 페이지(보드 만들기) 안에서 단계별로 진행 |
| ② | 가격을 처음 보여줄 위치 | 디자인 단계 하단에 함께 표시 |
| ③ | 저장한 디자인을 다시 볼 위치 | 내 디자인 페이지를 새로 둠 |
| ④ | 장바구니 | 장바구니를 추가함 |

### 페이지 묶음

| 페이지 | 묶은 기능 |
|---|---|
| 메인 | 브랜드 소개, 체험 시작 |
| 보드 만들기 | 1단계 길이 찾기, 2단계 디자인·미리보기, 가격 요약, 장바구니 담기, 저장 |
| 장바구니 | 담은 보드 확인, 빼기, 주문하기 |
| 주문·결제 | 주문 확인, 배송 정보, 가상 결제, 완료 |
| 내 디자인 | 저장한 디자인 목록, 다시 꾸미기, 장바구니 담기 |
| 로그인 | 저장 전 로그인 |

### 방문자 흐름별 페이지 구성

| 방문자 행동 | 필요한 정보·기능 | 배치할 페이지 / 섹션 | 다음 행동 |
|---|---|---|---|
| ① 사이트에 들어와 어떤 곳인지 파악함 | 한 줄 소개, "크기 → 디자인 → 구매" 흐름 안내, 체험 시작 버튼 | 메인 | 보드 만들기 시작 |
| ② 내게 맞는 길이를 찾음 | 키·신발 사이즈·타는 목적 입력, 22·27·32인치 중 추천 결과, 보드 용어 쉬운 설명 | 보드 만들기 › 1단계 길이 찾기 | 2단계 디자인 |
| ②-1 원하는 길이를 이미 알고 있음 | 추천 건너뛰기, 길이 직접 선택 | 보드 만들기 › 1단계 길이 찾기 | 2단계 디자인 |
| ③ 디자인을 고르고 완성된 모습을 봄 | 부품별 색(덱·바퀴·트럭), 덱 무늬, 미리보기, 길이 변경, 보드 용어 쉬운 설명 | 보드 만들기 › 2단계 디자인 | 가격 확인 |
| ④ 가격을 확인함 | 선택한 길이·디자인 요약, 보드 가격 (금액은 추후 결정) | 보드 만들기 › 2단계 디자인 하단 | 장바구니 담기 또는 저장 |
| ⑤ 장바구니에 담음 | 장바구니 담기, 담은 뒤 안내 | 보드 만들기 › 2단계 디자인 하단 | 장바구니로 이동 또는 계속 만들기 (추후 결정) |
| ⑥ 장바구니를 확인함 | 담은 보드 목록, 각 보드의 길이·디자인·가격, 빼기 | 장바구니 | 주문하기 |
| ⑦ 바로 사지 않고 디자인을 저장함 | 디자인 저장, 이미지 저장, 로그인 요청 | 보드 만들기 › 2단계 디자인 → 로그인 | 추후 결정 |
| ⑧ 저장한 디자인을 다시 봄 | 저장한 디자인 목록, 다시 꾸미기, 장바구니 담기 | 내 디자인 (로그인 필요) | 보드 만들기 또는 장바구니 |
| ⑨ 주문 내용을 확인함 | 주문할 보드 요약, 배송 정보 (기간·비용은 추후 결정) | 주문·결제 › 주문 확인 | 가상 결제 |
| ⑩ 결제를 마침 | 가상 결제, 주문 완료 안내 | 주문·결제 › 결제 → 완료 | 추후 결정 |

## 2. 추후 결정으로 남긴 사항

### 장바구니 관련
- [ ] 장바구니를 쓸 때 로그인이 필요한지
- [ ] 장바구니에 담은 뒤 바로 장바구니로 보낼지, 계속 만들 수 있게 할지
- [ ] 장바구니에서 보드 수량을 바꿀 수 있게 할지

### 로그인 관련
- [ ] 구매할 때도 로그인이 필요한지 (01 문서에는 저장할 때 로그인이 필요하다는 내용만 있음)
- [ ] 로그인·가입 방식

### 이후 행동 관련
- [ ] 디자인 저장을 마친 뒤 방문자의 다음 행동
- [ ] 결제를 마친 뒤 방문자의 다음 행동

### 인상 관련
- [ ] "믿고 살 수 있는 품질" 인상을 전달할 정보 (근거가 될 내용이 01 문서에 없음)

### 01 문서에서 이어지는 항목
- [ ] 구체적인 보드 가격
- [ ] 색과 덱 무늬의 종류와 개수
- [ ] 길이 추천 기준
- [ ] 배송 정보 (배송 기간, 배송비)
