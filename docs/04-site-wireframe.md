## 2. 표기 규칙 (범례)

| 요소 | 표기 |
|---|---|
| 글 | 실제 문구 (웹사이트와 같음) |
| 이미지 | X 상자 + 이름 |
| 입력 | 이름 + 안내 문구가 든 입력칸 |
| 선택 | 진한 칸·굵은 테두리가 현재 선택값 |
| 조절 | 붙어 있는 구간 버튼 |
| 버튼 | 회색 버튼 (보조는 흰 바탕 테두리, 글자 버튼은 밑줄) |
| 핵심 행동 | 굵은 검정 테두리 버튼 |
| 추후 결정 | 점선 상자 + '추후 결정' |
| ID·주석 | 파란색 (P 페이지, M 메뉴, S 섹션, B 버튼) |

> 헤더 메뉴(M01~M05)는 문서에 정해진 구성이 없어 페이지 목록으로 구성함 — 확정 필요. 상품명·옵션·수치는 화면 예시입니다.
